========================================================================
             SISTEMA LA EXTRA - INSTRUCCIONES DE INSTALACIÓN
========================================================================

Este paquete contiene todo lo necesario para ejecutar el Sistema de Gestión
La Extra en una nueva computadora con Windows.

------------------------------------------------------------------------
1. REQUISITO PREVIO OBLIGATORIO (Instalar Node.js)
------------------------------------------------------------------------
El sistema utiliza un módulo de WhatsApp que requiere Node.js para funcionar.
Siga estos pasos para instalarlo:

1. Descargue el instalador oficial de Node.js para Windows desde:
   https://nodejs.org/ (Se recomienda descargar la versión "LTS").
2. Abra el instalador descargado y siga las instrucciones del asistente de
   instalación (haga clic en "Siguiente" o "Next" en todo).
3. Asegúrese de que la casilla "Add to PATH" esté activada (se activa por defecto).
4. Complete la instalación.

------------------------------------------------------------------------
2. CÓMO INICIAR EL SISTEMA
------------------------------------------------------------------------
Una vez instalado Node.js:

1. Copie toda la carpeta "LaExtra_Release" a la computadora nueva (por ejemplo,
   al Escritorio o a Documentos).
2. Ejecute el archivo "SistemaLaExtra.exe" haciendo doble clic sobre él.
3. Se abrirá una terminal negra en segundo plano y se abrirá automáticamente
   su navegador de internet en la pantalla del sistema (http://localhost:5002).

------------------------------------------------------------------------
3. CONEXIÓN DE WHATSAPP
------------------------------------------------------------------------
1. Cuando abra el sistema por primera vez, vaya a la pestaña "Información"
   (o "Sistema").
2. En la sección "CONEXIÓN WHATSAPP", configure los siguientes datos por defecto:
   - URL del Servidor: http://localhost:8080
   - API Key / Token: laextra
   - Instancia: laextra
3. Guarde la conexión.
4. Luego, vaya a la pestaña "WhatsApp" en la barra de navegación del sistema y
   escanee el código QR con su teléfono para conectar su cuenta.

------------------------------------------------------------------------
4. PERSISTENCIA DE DATOS Y RESPALDOS
------------------------------------------------------------------------
- Los datos de los pedidos, clientes, catálogo y configuraciones se guardan de
  forma segura y automática en su disco local (en la ruta:
  %LOCALAPPDATA%\SistemaLaExtra\data.json).
- Si desea hacer un respaldo de su información, puede ir a la sección "Sistema"
  en la pestaña de Información y hacer clic en "BACKUP DATA", o copiar el archivo
  data.json mencionado anteriormente.
