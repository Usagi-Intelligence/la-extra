# Frontend Design: Avoiding Generic "AI Slop"

## Overview
This skill guides the creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. It pushes you to implement real working code with a unique aesthetic voice.

## Core Directives
1. **Avoid the Generic:** Move beyond plain, standard AI-generated layouts (e.g., simple cards with basic borders, standard Bootstrap/Tailwind look without character).
2. **Distinct Aesthetic Voice:** Apply specific design languages (e.g., retro-futuristic, brutalist, minimal glassmorphism, high-contrast maximalism) rather than a default "clean" look.
3. **Typography & Color:** Pay deep attention to typography scales, custom fonts, curated color palettes, and deliberate whitespace.
4. **Interaction:** Include thoughtful micro-interactions, hover states, and transitions that make the UI feel alive and polished.

## Workflow
When tasked with designing or building UI:
- **Analyze context:** Who is the target audience? What is the emotional tone?
- **Define aesthetic:** Choose a clear design direction before writing CSS/styling.
- **Iterate:** Refine typography, spacing, and colors to achieve a premium, differentiated look.
